# UI設計

## デザイン方針

- ブラウザ横幅いっぱいに表示
- ブラウザのズーム・リサイズに追従するレイアウト（`height: 100dvh` + `overflow: auto`）
- レトロゲーム（RPG）風のデザイン
- ピクセルフォント（Press Start 2P）をヘッダー・ラベル・ボタンに使用
- カードはRPGのアイテムカード風、ホバーで浮き上がるエフェクト
- ボタンはピクセルシャドウ付きの3D風
- サイドバーのナビゲーションはカーソル（▶）選択式

## 画面構成

### ログイン画面

- 中央にログインフォーム（ユーザー名・パスワード）
- ゲームタイトル風のヘッダー

### メイン画面（レシピ一覧）

- 左サイドバー: 幅 260px / メニュー + ドメインフィルタ + ユーザー情報
- 上部ツールバー: ドメイン・タグフィルタ + 新規登録ボタン
- メインエリア: レシピカードグリッド（3列固定 `repeat(3, 1fr)`）
- 下部ステータスバー: 件数・フィルタ状態表示

### レシピ詳細・登録・編集モーダル

- サイズ: 98vw × 97vh（maxWidth制限なし）
- 左カラム（flex: 1）: タイトル / ドメイン / タグ / 説明・注意点 / ボタン（保存・削除・ER図）
- 右カラム（flex: 2）: SQLエディタ（CodeMirror 6 / ダークテーマ / シンタックスハイライト / 行番号表示）＋ コメント折りたたみ
- コメント: 右カラム下部（SQL下）に折りたたみ式で表示
  - 折りたたみバーに件数表示
  - 展開するとgit風の時系列スレッド（maxHeight 320px で独立スクロール）
  - 各コメントに編集・削除ボタン
  - 入力フォームはスクロール外に固定表示
- SQLエリアとコメントエリアはそれぞれ独立してスクロール

### ER図モーダル

- サイズ: 95vw × 90vh
- テーブル名のノードと、JOINキーを示すエッジのみ表示
- カラム詳細は表示しない
- node-sql-parserでSQLを自動パース、補正機能なし
- Mermaid.js でER図をダイアグラム描画

### 管理者画面（モーダル）

- サイズ: 90vw × 90vh（maxWidth 1100px）
- ユーザー管理: 一覧・作成・編集・パスワードリセット
- ドメイン管理: 一覧・作成・編集・削除
- タグ管理: 一覧・作成・編集・削除

## フォントサイズ方針

Press Start 2P はピクセルフォントのため、同じpxサイズでも通常フォントより小さく見える。各箇所の目安：

| 箇所 | フォント | サイズ |
|------|---------|-------|
| アプリタイトル | Press Start 2P | 22px |
| モーダルヘッダー | Press Start 2P | 14px |
| サイドバー項目 | Press Start 2P | 14px |
| ツールバーラベル/ボタン | Press Start 2P | 11〜12px |
| カードタイトル | Press Start 2P | 18px |
| カードタグ/フッター | Press Start 2P | 11px |
| 入力フォーム | monospace | 15〜16px |
| 本文・説明 | monospace | 13〜15px |

## テーマ切り替え

3種類のテーマを切り替えられる。選択はlocalStorageに保存（キー: `theme`）。

| テーマ名 | フォント | 雰囲気 |
|---------|---------|--------|
| Retro（デフォルト） | Press Start 2P | ピクセルアート・RPG |
| Modern | Noto Sans JP | クリーン・ミニマル |
| Italian | Playfair Display + Noto Sans JP | 高級感・イタリアンレストラン |

切り替えUIはサイドバー最下部に配置。詳細は `docs/superpowers/specs/2026-04-17-theme-switcher-design.md` を参照。

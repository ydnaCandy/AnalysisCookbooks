# UI設計

## デザイン方針

- ブラウザ横幅いっぱいに表示
- レトロゲーム（RPG）風のデザイン
- ピクセルフォント（Press Start 2P）をヘッダー・ラベル・ボタンに使用
- カードはRPGのアイテムカード風、ホバーで浮き上がるエフェクト
- ボタンはピクセルシャドウ付きの3D風
- サイドバーのナビゲーションはカーソル（▶）選択式

## 画面構成

### ログイン画面

- 中央にログインフォーム（ユーザー名・パスワード）
- ゲームタイトル風のヘッダー

### メイン画面（レシピ一覧）

- 左サイドバー: メニュー + ドメインフィルタ + ユーザー情報
- 上部ツールバー: ドメイン・タグフィルタ + 新規登録ボタン
- メインエリア: レシピカードグリッド（3列）
- 下部ステータスバー: 件数・フィルタ状態表示

### レシピ詳細・登録・編集モーダル

- 左カラム（flex: 1）: タイトル / ドメイン / タグ / 説明・注意点 / ボタン（保存・削除・ER図）/ コメント折りたたみ
- 右カラム（flex: 2）: SQLエディタ（ダークテーマ、左寄せ）
- コメント: 左カラム下部に折りたたみ式で表示
  - 折りたたみバーに件数表示
  - 展開するとgit風の時系列スレッド
  - 各コメントに編集・削除ボタン
  - 下部に新規コメント入力欄

### ER図モーダル

- テーブル名のノードと、JOINキーを示すエッジのみ表示
- カラム詳細は表示しない
- node-sql-parserでSQLを自動パース、補正機能なし
- @xyflow/react でノードベースのグラフ描画

### 管理者画面（モーダル）

- ユーザー管理: 一覧・作成・編集・パスワードリセット
- ドメイン管理: 一覧・作成・編集・削除
- タグ管理: 一覧・作成・編集・削除

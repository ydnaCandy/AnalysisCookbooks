# データ分析クックブックアプリのアイデア

## 背景/課題

- 社内のデータを使って、可視化/分析する際に、テーブル名や適切な処理を調べるのにかなり時間がかかる
- １度可視化や分析に使ったSQLを保存しておく仕組みを作りたい

## 実現したいこと

### 機能系

- 分析のドメイン領域（製造、営業、経営など）ごとに分析レシピ（SQL）を管理したい
  - 分析レシピごとに関連システム、サービスなどをタグ付けできるようにしたい
  - SQLからER図を表示させたい
    - ER図表示ボタンでsqlを下にer図を表示する
    - from内で呼び出されているテーブルと結合テーブルとキーがer図で分かればOK
    - サブクエリやwith句が使われた場合は、サブクエリやwith句単位で表示
  - 分析レシピごとにデータの見方の注意点をコメントできるようにする
- 簡易的でいいのでユーザー管理もしたい
  - ログイン機能（社内なので簡易的でOK）
  - パスワードの平文管理はNG
  - パスワード初期化機能は必須
  - 管理者機能をつける
- 管理者の機能
  - ユーザー登録
  - ドメイン領域やシステム名などのマスタ管理

### 画面系

- 左側側にメニュー、右側がメインコンテンツ
- レシピの表示、登録、編集はモーダル表示で
  - ER図の表示もモーダルで

## 技術選定

### ディレクトリ構成

- backend
  - バックエンド関連のプログラムを管理
- frontenc
  - フロントエンド関連のプログラムを管理

### バックエンド

- 言語
  - python
- ライブラリ
  - fastapi
- 環境管理
  - uv

### フロントエンド

- 言語
  - typescript
- フレームワーク
  - react
- 環境管理
  - npm/vite

### 最終的なリリース環境

- dockerコンテナでのリリースを想定
- docker composeでデプロイしたい


## UI
- ブラウザの横幅いっぱいにアプリケーションが表示されるようにしてください。

- レシピ登録/表示用のモーダルについて
    - タイトル、説明、ドメインを画面の左側、右側にSQLを入力できるようにしてください
    - SQLは左寄せで入力できるようにしてください。

- ER図モーダルについて
    - モーダルは表示されますが、テーブル名が記載されていません



## 1. UI 全体方針・スタイル設計

- **デザインシステム**: Tailwind CSS (v4) を主軸とするユーティリティファーストCSS。
- **テーマ**: ライトグレー基調（白よりのグレー）。レトロゲーム風の遊び心を取り入れる。
- **アイコン**: Lucide-React を採用。

## その他

### サンプルデータの登録
- 初回ログイン用のユーザーを登録するプログラムを作成してください。
    - admin権限を付与してください。
- サンプルデータを登録するプログラムを作成して下さい

### リリース手順の作成
- release/を作ってリリース手順をmdファイルにしてください。
- 最終的にはlinuxサーバー上でdocker-composeで起動します。
    - DB関連はバックエンドを簡易的にするために、ホスト側にマウントする設定にしてください。
- エージェントによるテストは不要です。私がやります。
